# Фронтенд приложения для расчёта экономии топлива при использовании круиз-контроля

**Лабораторная работа №5** (Разработка базового SPA на React)

Базовое SPA-приложение на React + TypeScript (сборщик Vite). Интерфейс выполнен в виде мобильного приложения: колонка шириной до 430 px по центру экрана. На данном этапе (ЛР5) реализован гостевой каталог автомобилей с расходом топлива и объёмом бака. Приложение работает **только с mock-данными**, без подключения к бэкенду, базе данных и S3.

## Стек технологий

- React (функциональные компоненты, хуки).
- TypeScript (строгая типизация).
- Vite (сборщик и dev-сервер).
- React Router DOM v7 (маршрутизация).
- React-Bootstrap и Bootstrap (UI-компоненты).
- Собственные SVG-иконки (компонент CarIcon).
- Чистый CSS.
- Redux и пользовательский React Context в данной работе не используются.

## Запуск проекта

Требуются Node.js 24 LTS и npm. Команды выполняются из корня проекта, в ветке `fuel_consumptions-react-mock`.

1. Установите зависимости: `npm install`.
2. Запустите сервер разработки (порт 3000): `npm run dev`.
3. Откройте в браузере: [http://localhost:3000/fuel_consumptions](http://localhost:3000/fuel_consumptions).

## Структура проекта

- `src/modules/fuel_consumptions.ts` — интерфейсы автомобиля и диапазона расхода топлива.
- `src/modules/mock.ts` — массив из 5 mock-карточек автомобилей.
- `src/components/FuelImage.tsx` — изображение по умолчанию и пути резервных медиа.
- `src/Routes.ts` — константы маршрутов.
- `src/components/` — переиспользуемые компоненты: TabBar, ConsumptionFilter, FuelConsumptionCard, FuelImage и CarIcon.
- `src/pages/` — страницы ленты и плитки автомобилей.
- `src/App.tsx` — маршрутизация, состояние диапазона и фильтрация mock-коллекции.
- `src/MobileApp.css` — оформление приложения по образцу ЛР2.
- `public/` — локальные изображения, видео и резервные медиафайлы.

## Описание страниц приложения (Поля и Кнопки)

Нижняя панель навигации (TabBar) содержит **4 пункта**. На данном этапе работают только два из них: **«Лента» и «Плитка»**. Пункты **«Добавление» и «Вход»** неактивны. Значки одинакового размера расположены в четырёх равных колонках; активный пункт подсвечен жёлтым.

### 1. Страница «Лента» (маршрут /fuel_consumptions/feed/:id)

Вертикальная карточка автомобиля с автоматически воспроизводимым видео и информацией поверх него. `:id` — идентификатор автомобиля.

- **Элементы отображения:** видео на фоне, название автомобиля, описание, объём бака в литрах, расход в л/100 км, значок сердца и количество лайков.
- **Поля:** поля ввода отсутствуют.
- **Кнопки:**
  - «Ещё» / «Меньше» — раскрывает и сворачивает описание.
  - «Следующий автомобиль» — круглая жёлтая кнопка со стрелкой; открывает следующую карточку текущего списка, после последней — первую.
  - «К плитке» — появляется при пустой ленте или неизвестном ID автомобиля.
- **Лайки:** в интерфейсе гостя отображается только счётчик; поставить или снять лайк в ЛР5 нельзя.

### 2. Страница «Плитка» (маршрут /fuel_consumptions)

Сетка карточек автомобилей в 2 колонки с фильтрацией по расходу топлива.

- **Элементы отображения:** карточки с изображением, названием, расходом топлива и количеством лайков; счётчик найденных автомобилей.
- **Поля:**
  - «От» (числовое поле) — нижняя граница расхода от 0 до 60 л/100 км, шаг 0,1.
  - «До» (ползунок) — верхняя граница от 0 до 60 л/100 км, шаг 0,1. Текущее значение показано рядом.
- **Кнопки:**
  - «Показать автомобили» — применяет диапазон к mock-коллекции. Работает также отправка формы клавишей Enter.
  - «Сбросить фильтр» — появляется после применения диапазона; очищает поле «От», возвращает ползунок к 60 и показывает все карточки.
  - Клик по карточке — открывает ленту с выбранного автомобиля.
- **Поведение фильтра:** границы включаются в результат. Если нижняя граница больше верхней, кнопка применения отключена. Пустой результат показывает сообщение «Автомобили не найдены». Применённый диапазон сохраняется при переходах между страницами и сбрасывается при перезагрузке приложения.

### 3. Раздел «Добавление» — заглушка

Пункт неактивен в нижнем меню. Отдельная страница и маршрут добавления в ЛР5 не реализованы.

- **Элементы отображения:** значок «+» и подпись «Добавление» в меню.
- **Поля:** отсутствуют.
- **Кнопки:** пункт меню отключён, переход и создание автомобиля недоступны.

### 4. Раздел «Вход» — заглушка

Пункт неактивен в нижнем меню. Отдельная страница и маршрут входа в ЛР5 не реализованы.

- **Элементы отображения:** значок входа и подпись «Вход» справа в меню.
- **Поля:** отсутствуют.
- **Кнопки:** пункт меню отключён, авторизация недоступна.

## Медиафайлы и заглушки

Изображения и видео автомобилей хранятся локально в папке `public/fuel_consumptions/`. Если `image_url` или `video_url` пусты либо файл не загрузился, используется соответствующий резервный файл из проекта:

- `public/DefaultImage.jpg` — изображение автомобиля с надписью «Нет изображения».
- `public/DefaultVideo.mp4` — трёхсекундная анимация «Видео отсутствует», без звука, с циклическим воспроизведением.

У mock-карточки **«Автомобиль без медиа» (ID 5)** оба поля пустые: в плитке видно резервное изображение, в ленте воспроизводится резервное видео. Фото и видео сохраняют исходные пропорции. Источники автомобильных медиа указаны в [CARS_MEDIA_CREDITS.md](public/fuel_consumptions/CARS_MEDIA_CREDITS.md).
