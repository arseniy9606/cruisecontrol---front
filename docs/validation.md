# Проверка ЛР5

9 ноября 2026 года. Проверены `npm run build` (включает tsc --noEmit) и браузерные сценарии в Google Chrome.

- Пять mock-карточек, два активных и два отключённых пункта меню.
- Диапазон 8–13 применяется только после отправки формы: три автомобиля. Значения сохраняются при возврате из ленты.
- Листание по найденному списку: ID 2 → 3 → 5 → 2. Описание сворачивается при смене автомобиля.
- Диапазон 90–100 оставляет пустую плитку и пустую ленту; сброс возвращает пять карточек.
- Перепутанные границы блокируют поиск. Поиск по Enter работает.
- У ID 5 загружаются локальные DefaultImage.jpg и DefaultVideo.mp4; видео достигает readyState ≥ 2.
- Прямой адрес неизвестной карточки показывает состояние ленты; неизвестный маршрут перенаправляется в плитку.
- При ширине 320 px нет горизонтального переполнения.
- Ошибок JavaScript и запросов fetch/XHR нет, ресурсы загружаются с localhost.
- Обе страницы дополнительно просмотрены в Chrome с настоящей вкладкой Network; фрагменты окна включены в отчёт.

Docker-вариант предоставлен как дополнительный способ запуска; проверка интерфейса выполнялась через Vite без Docker.
